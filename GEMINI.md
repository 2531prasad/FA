# Gemini project entry point

Read and follow `AGENTS.md` for the shared project instructions and `AGENT_WORKFLOW.md` for the report workflow. The same files guide Claude and Codex.

Quick start: `npm start`, then `node scripts/report.mjs list`. Publish complete Markdown with `node scripts/report.mjs create`, or refine a report with `node scripts/report.mjs revise`. Dates and original revisions must remain explicit. See `templates/report.md`.
